AI Account Bridge 사용 설명서

ChatGPT(Codex)·Claude 데스크톱 앱의 계정 전환과 대화 옮기기

v{{version}} · Windows
계정 전환ChatGPT(Codex 앱)와 Claude 데스크톱 앱의 계정을 로그아웃 없이 한 번에 바꿉니다.
대화 옮기기Codex ↔ Claude, Claude 계정 A → B로 대화(세션)를 옮겨 이어서 작업합니다.
원본은 그대로옮길 때 원본은 건드리지 않고 받는 쪽에 새 세션을 만듭니다.

1설치

  1. AI Account Bridge_{{version}}_x64-setup.exe(약 25MB)를 실행합니다.
  2. “Windows의 PC 보호” 창이 뜨면 [추가 정보] → [실행]을 누릅니다. 코드 서명이 없어서 뜨는 안내입니다.
  3. 관리자 계정이면 사용자 계정 컨트롤 창이 뜹니다 → [예].
  4. 설치 범위(나만 쓰기 / 이 컴퓨터를 쓰는 모든 사용자)를 고르고 [다음] → [설치] → [마침]. 시작 메뉴에 AI Account Bridge가 생깁니다.
  • Windows 10/11 64비트용입니다. 화면을 그리는 WebView2는 Windows 11에 기본으로 들어 있고, 없으면 설치 중에 자동으로 내려받습니다(인터넷 필요).
  • 새 버전은 설치 파일을 그대로 실행하면 이전 버전(0.2.0 이상) 위에 설치됩니다. 0.1.0을 설치했다면 먼저 설정 → 앱에서 제거하세요. 어느 쪽이든 등록한 계정은 그대로 남습니다.
  • 제거: 설정 → 앱 → AI Account Bridge → 제거. 등록한 계정·백업(%USERPROFILE%\.ai-account-bridge)은 남습니다.

2화면 구성

  • 1계정 막대 — 도구별 현재 계정. 눌러서 전환합니다(초록 점 = 등록된 계정).
  • 5받는 곳 — 대화를 옮길 대상(ChatGPT / Claude 계정).
  • 2보내는 도구 — ChatGPT / Claude. 오른쪽에서 계정별로 거릅니다.
  • 6상태 표시줄 — 마지막 작업 결과. 누르면 활동 기록이 열립니다.
  • 3세션 목록 — ChatGPT는 Codex 앱과 같은 프로젝트별로(나머지는 “프로젝트 없음”), Claude는 작업 폴더별로 묶입니다.
  • 7활동 기록 — 작업 기록과 백업 복원.
  • 4가져오기 — 고른 세션을 받는 곳으로 옮깁니다.

3계정 전환

처음 한 번: 지금 로그인한 계정 저장

  1. ChatGPT(Codex) 또는 Claude 앱에 평소처럼 로그인합니다.
  2. 계정 막대를 눌러 [현재 로그인 저장…]을 누르고 이름(예: 회사 계정)을 붙입니다. 아직 등록하지 않은 로그인은 메뉴 맨 위에 “등록되지 않은 로그인”으로 보이며, 옆의 [저장…]으로도 됩니다.

다른 계정 추가

  1. 메뉴에서 [새 계정 추가]를 누르면 지금 계정을 저장한 뒤 앱이 로그인 화면으로 다시 열립니다.
  2. 앱에서 새 계정으로 로그인하고, 위와 같이 [저장…]합니다.
앱 안에서 “로그아웃”하지 마세요. 그 계정의 로그인이 서버에서 폐기되어 저장해 둔 계정도 쓸 수 없게 됩니다. 계정을 늘릴 때는 항상 [새 계정 추가]를 씁니다.

전환

메뉴에서 바꿀 계정을 누르면 앱을 닫고 → 로그인 정보를 바꾸고 → 다시 엽니다(몇 초). 계정 줄에 마우스를 올리면 나오는 연필·휴지통으로 이름 변경·삭제를 합니다. 삭제는 이 앱의 저장본만 지우고 앱의 실제 로그인은 그대로 둡니다.

ChatGPT는 계정을 바꿔도 대화 목록이 그대로입니다. Codex 세션은 이 PC에 저장되어 어느 GPT 계정으로 로그인해도 같은 목록이 보이므로, GPT 계정끼리는 대화를 옮길 필요가 없습니다. 그래서 받는 곳도 “ChatGPT · 모든 계정” 하나입니다.

4활동 기록과 백업 복원

작업 결과는 상태 표시줄과 오른쪽 위 활동 기록에 남고, 경고·오류는 알림으로 뜹니다.

계정을 전환하기 전의 로그인은 자동으로 백업됩니다. 전환이 꼬였다면 [활동 기록] → [백업에서 복원…]에서 백업 파일을 고르면 그때 상태로 되돌아갑니다.

5대화(세션) 옮기기

  1. 왼쪽에서 도구를 고르고 옮길 세션을 선택합니다. Ctrl·Shift+클릭으로 여러 개, 프로젝트 체크박스로 한꺼번에 고릅니다.
  2. 오른쪽 위에서 받는 곳을 고릅니다.
  3. 오른쪽으로 끌어다 놓거나 가운데 화살표(Ctrl+Enter)를 누릅니다.
  4. 확인 창에서 [가져오기]. 받는 앱이 켜져 있으면 닫았다가 다시 엽니다.
보내는 쪽 → 받는 쪽결과
ChatGPT → ClaudeClaude의 Code 탭에 [Codex] 제목으로 추가
Claude → ChatGPTCodex 앱에 [Claude] 제목으로 추가
Claude 계정 A → BB 계정에 복사본을 만듦(Code 세션만)
  • 도구 실행 기록은 한 줄 요약만 옮깁니다(도구 실행 기록 전부 넣기를 켜면 전부). 붙인 이미지·첨부 파일 경로도 옮겨집니다.
  • 첫머리에 옮겨 왔다는 안내와 작업 폴더의 git 저장소별 브랜치·커밋하지 않은 변경이 붙습니다.
  • 지침 파일도 복사: AGENTS.md ↔ CLAUDE.md를 받는 쪽 형식으로 만듭니다(하위 저장소 포함).
  • 이미 옮긴 세션은 건너뛰기(기본) 또는 새 복사본을 고릅니다. 옮긴 세션에는 이관됨 표시가 붙습니다.
  • 받는 쪽에 세션이 하나는 있어야 합니다. 없으면 받는 앱에서 새 대화를 하나 만든 뒤 다시 시도하세요.
  • GPT 대화 폴더도 복사해 따로 쓰기: 프로젝트 없이 시작한 GPT 대화를 Claude로 옮길 때 그 폴더를 복사해 따로 씁니다.

6대화 미리보기

세션을 더블클릭(또는 Enter, 눈 아이콘)하면 오른쪽에 대화가 열립니다. 답변은 마크다운으로 보이고, 이어진 도구 호출은 “도구 호출 N개” 한 줄로 접혀 있다가 누르면 펼쳐집니다. 미리보기 위의 버튼으로 바로 가져올 수도 있습니다.

8자주 묻는 질문

옮긴 대화가 받는 앱에 안 보여요.
받는 앱을 트레이까지 완전히 종료한 뒤 다시 열어 보세요.
ChatGPT 계정을 바꾸면 대화 목록도 바뀌나요?
아니요. Codex 세션은 PC에 저장되어 계정과 상관없이 같은 목록이 보입니다(chatgpt.com 웹 대화는 이 앱과 무관).
이 앱에서 계정을 지우면 앱 로그인도 사라지나요?
아니요. 이 앱의 등록·저장본만 지웁니다.
프로그램을 지우면 데이터는요?
%USERPROFILE%\.ai-account-bridge에 남습니다. 완전히 지우려면 이 폴더도 삭제하세요.
