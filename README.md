# AI Account Bridge (가칭)

ChatGPT(Codex) · Claude 데스크탑 앱의 **여러 계정 전환**과, 로컬 **프로젝트/세션/대화의 계정 간·도구 간 이관**을 돕는 Windows 데스크탑 앱.

- 계정 등록 & 원클릭 전환 (인증 파일만 교체, 로컬 세션은 공유)
- 계정별 로컬 프로젝트 → 세션 → 대화 조회
- Codex ↔ Claude Code 세션 양방향 변환 후 대상 앱에서 이어서 작업

> 상태: Plan 1(코어 + 계정 전환), Plan 2(조회), Plan 3(이관) 구현 완료. 실제 앱 검증: V1·V6·V7 통과, V2~V5·V9 대기 — [이관 검증 기록](docs/verification/phase0-migration.md).

## 설치

`AI Account Bridge_<버전>_x64-setup.exe`(약 25MB)를 실행하면 설치 마법사가 뜬다 — 설치 범위(나만/모든 사용자)와 폴더를 고르면 시작 메뉴·바탕 화면 바로 가기를 만들고, 끝나면 앱을 실행할 수 있다. 설치본에는 백엔드가 들어 있어 Node 가 필요 없다. 화면은 Windows 의 WebView2 로 그린다(Windows 11 은 기본 포함, 없으면 설치 중에 내려받는다).

- 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있다 → [추가 정보] → [실행].
- 제거해도 등록한 계정·스냅샷·백업(`~\.ai-account-bridge`)은 남는다.
- 직접 만들기: Rust(MSVC) 툴체인과 Microsoft Edge(설명서 PDF 인쇄)가 필요하다. `npm run dist` → `dist\` 에 배포할 것만 모인다 — 설치 파일과 `AI Account Bridge 사용 설명서.pdf`(매번 비우고 새로 채운다, `scripts/build-dist.mjs`). 창은 Tauri 이고, 백엔드(`src/rpc/server.ts`)는 `scripts/build-sidecar.mjs` 가 Node 단일 실행 파일(SEA)로 묶은 사이드카로 실행된다(better-sqlite3 네이티브 모듈은 실행 파일 옆에 둔다). 설치 마법사 설정은 `src-tauri/tauri.conf.json` 의 `bundle`.

## GUI

```bash

```

화면은 상단 계정 막대와 보내는 쪽 → 받는 쪽 전송 화면으로 되어 있다(레퍼런스: GitHub Desktop, Transmit). `npm run gui` 는 백엔드 사이드카를 만든 뒤 `tauri dev` 로 창을 띄운다(Rust 툴체인 필요). Claude 를 전환하거나 Claude 로 가져오면 Claude Desktop 이 종료되지만 이 GUI 는 별도 프로세스라 계속 남는다.

### 상단 막대: 계정 전환

- 도구(ChatGPT / Claude)마다 현재 로그인한 계정이 항상 보인다(초록 점 = 등록된 계정, 주황 점 = 등록되지 않은 로그인). 누르면 계정 메뉴가 열린다.
- 메뉴에서 다른 계정을 누르면 전환한다. 앱이 창을 닫아도 트레이로 숨는 경우가 많아, 정상 종료 요청 후 3초 안에 닫히지 않으면 자동으로 강제 종료한다. 진행 단계는 막대와 아래 상태 표시줄에 보인다.
- 계정 행의 연필·휴지통으로 이름 변경·삭제. 삭제는 앱의 실제 로그인은 두고 이 도구의 등록·스냅샷만 지운다.
- `새 계정 추가`는 현재 계정을 저장·백업한 뒤 **로그아웃 없이** 로그인 정보만 비우고 앱을 다시 연다 — 앱 안에서 로그아웃하면 그 계정의 토큰이 서버에서 폐기되므로 다른 계정을 추가할 때는 이것을 쓴다. 새 계정으로 로그인하면 메뉴에 "등록되지 않은 로그인"으로 나타나고 거기서 저장한다.
- `앱 프로필도 함께 저장·교체`(검증용)를 켜면 쿠키·로컬 저장소까지 스냅샷·교체한다.

### 보내는 쪽 → 받는 쪽: 세션 가져오기

- 왼쪽(보내는 쪽)은 도구·계정·검색어·서브에이전트/보관됨으로 거른 로컬 세션 목록(읽기 전용)이다. Codex 세션은 앱 사이드바와 같은 프로젝트로 묶이고(앱에서 지정한 프로젝트·작업 트리 포함), 나머지 대화는 `프로젝트 없음` 한 묶음이다. Claude 세션은 작업 폴더별로 묶인다.
- 파일 탐색기처럼 클릭으로 고르고(Ctrl·Shift+클릭, 체크박스, 프로젝트 체크박스로 여러 개), 오른쪽(받는 쪽)으로 **끌어다 놓거나** 가운데 화살표(Ctrl+Enter)를 누르면 확인 창이 뜬다. 프로젝트 머리글을 끌면 그 안의 세션을 한꺼번에 옮긴다. ⇄ 버튼은 보내는 쪽과 받는 쪽을 맞바꾼다.
- 받는 쪽에서 대상(ChatGPT(Codex) 또는 Claude 계정)을 고르면 그곳에 이미 있는 세션이 보이고, 방금 가져온 세션은 맨 위에 표시된다.
- 더블클릭(또는 Enter, 눈 아이콘)하면 오른쪽 위에 대화 미리보기가 열린다(메시지 300개·2000블록·텍스트 8000자까지). 답변은 마크다운으로 보이고, 이어진 도구 호출은 `도구 호출 N개` 한 줄로, 아주 긴 사용자 메시지는 열 줄로 접혀 있다가 누르면 펼쳐진다.
- 단축키: Ctrl+F 검색, F5 새로고침, Ctrl+A 모두 선택, Esc 닫기/선택 해제, ↑/↓·Space·Enter 목록 이동·선택·미리보기.
- 결과는 상태 표시줄과 `활동 기록`(상단 오른쪽, 상태 표시줄을 눌러도 열린다)에 남고, 경고·오류는 알림으로 뜬다. 전환 전 로그인 백업은 활동 기록의 `백업에서 복원…`으로 되돌린다.

| 원본 → 대상 | 동작 |
|---|---|
| Codex → Claude | 세션을 변환해 선택한 Claude 계정(현재 로그인 계정 또는 등록된 계정)의 Code 탭 목록에 `[Codex] 제목` 으로 추가 |
| Claude Code / Cowork → Codex | 변환해 ChatGPT(Codex) 앱에 `[Claude] 제목` 으로 추가 (Cowork 는 `userSelectedFolders[0]` 을 작업 폴더로 사용) |
| Claude 계정 A → B | **복사본(포크)**: 새 세션 ID 로 대화 파일을 복사하고 B 계정 목록에 추가 — 원본 계정의 세션과 따로 이어진다. Claude Code 세션만 가능 |

- 원본은 바뀌지 않는다. 대상 앱은 종료됐다가(실행 중이었다면) 다시 실행된다. 한 번에 최대 200개, 대화 기록이 없는 세션은 고를 수 없다.
- 이미 이관한 세션은 "건너뛰기"(기본) 또는 "새 복사본 만들기"를 고른다. 이관된 세션은 목록에 `이관됨` 배지가 붙는다.
- 세션마다 독립적으로 처리되며, 실패한 세션은 만든 파일을 되돌린다. 되돌리기까지 실패하면 결과에 수동 확인이 필요하다는 안내(대상 도구, 새 세션 ID)가 표시된다.
- 대상에 템플릿으로 쓸 기존 세션이 있어야 한다 — 대상 Claude 계정에서 Code 세션을, Codex 에서 세션을 하나 만든 뒤 다시 시도한다.
- 도구 실행 기록은 기본적으로 **한 줄 요약**만 옮긴다 — 실행한 명령·고친 파일·검색어를 호출마다 한 줄(160자 이내)씩, 결과는 실패한 호출만 앞 300자. 실제 세션을 재 보면 도구 입력·출력이 이관 글의 75~88% 를 차지하는데, 결과는 다음 답변이 요약하고 파일은 디스크에 있으므로 요약하면 분량이 1/5~1/3 로 줄고 받는 쪽 문맥 한도를 넘는 세션도 크게 준다. `도구 실행 기록 전부 넣기`(CLI `--full-tool-log`)를 켜면 예전처럼 입력·결과(각 2KB 까지)를 모두 옮긴다. 추론(reasoning)은 버려지고 대화 첫머리에 이관 안내가 붙는다. 앱이 사용자 메시지에 덧붙인 문맥(첨부 파일 목록, 선택한 텍스트, 앱 내 브라우저 상태 등)은 `[첨부: C:/…/보고서.pdf]` 같은 한 줄로 줄인다 — 첨부·선택한 파일은 옮긴 뒤에도 다시 열 수 있게 전체 경로를 남긴다.
- 새 세션은 원본과 같은 작업 폴더(GPT 의 대화 폴더 `Documents\Codex\날짜\이름` 포함)를 가리킨다. 폴더 안의 파일·git 저장소는 복사하지 않고 그 자리의 것을 그대로 쓴다. 대화 기록은 도구마다 따로 저장되므로 한쪽에서 대화를 지워도 다른 쪽 대화는 남지만, 폴더 자체를 지우면 양쪽 다 파일을 잃는다.
- Claude 로 가져올 때 같은 폴더가 다른 경로 표기(링크·정션 — 예: 사용자 폴더 이름을 바꾸고 남은 `C:\Users\옛이름`)로 기록돼 있으면 한 표기로 맞춘다: Claude 가 그 폴더에 이미 쓰는 표기가 있으면 그것을, 없으면 실제 경로를 쓰고 대화 속 경로도 그 표기로 바꾼다. Claude 는 경로 문자열로 프로젝트를 나누므로 맞추지 않으면 같은 폴더의 세션이 다른 프로젝트로 갈라진다. 실제 경로가 다른 드라이브로 풀리는 경우(subst·네트워크 드라이브)는 원래 표기를 둔다.
- 작업 폴더나 그 아래 2단계 폴더에 git 저장소가 있으면 옮긴 대화 첫머리에 `[작업 폴더 상태]`를 붙인다 — 저장소마다 브랜치와 커밋하지 않은 변경(`git status` 기준, 저장소당 20개까지). 상위 폴더는 git 저장소가 아니고 하위 저장소를 여럿 모은 폴더(예: `multi-repo`)도 저장소별로 적는다. git 을 실행할 수 없으면 그 저장소는 "변경 목록을 읽지 못했습니다" 로 남는다.
- `GPT 대화 폴더도 복사해 따로 쓰기`(기본 꺼짐, ChatGPT → Claude 이고 프로젝트 없이 시작한 GPT 대화일 때만 보인다)를 켜면 그 대화 폴더를 git 저장소째 `Documents\Claude\날짜\이름`(있으면 `이름 (2)`, `이름 (3)` …)으로 복사하고 새 Claude 세션이 복사본을 쓴다. 원본은 그대로이고 이후 두 폴더는 따로 바뀐다. 옮긴 대화 속 원본 폴더 경로(도구 호출·답변의 링크 등)는 복사본 경로로 바꾸고, 대화 첫머리에 그렇게 바꿨다는 `[작업 폴더 안내]` 를 붙인다 — 이어서 작업할 때 AI 가 예전 경로로 원본을 고치지 않게. 한 번에 가져오는 같은 폴더의 세션들은 복사본 하나를 같이 쓰고, 가져오기가 실패하면 복사본도 지운다. 원래 폴더가 없거나 복사하지 못하면(예: 폴더 안의 링크·정션을 만들 권한이 없을 때) 원래 폴더를 같이 쓰며 결과에 경고로 표시한다. 복사본 안의 Python 가상환경(venv)은 원본 경로를 가리키므로 쓰기 전에 다시 만드는 것이 안전하다. 실제 프로젝트 폴더는 복사하지 않는다.
- 사용자 메시지에 붙인 이미지도 실제 이미지로 옮긴다(PNG·JPEG·GIF·WebP, 장당 5MB 이하, 세션당 최근 20장·합계 20MB). Claude 로는 긴 변 2000px 이하만 옮기고(요청당 이미지가 20장을 넘으면 Claude API 가 그보다 큰 이미지를 거부한다), 나머지는 `[이미지]` 표시로 남긴다. Codex 로 옮긴 이미지는 앱이 보여 줄 수 있게 `~\.ai-account-bridge\images\codex\<세션>\` 에 파일로도 저장한다.
- `지침 파일도 복사`(기본 꺼짐)를 켜면 대상 작업 폴더에 `CLAUDE.md`(`@AGENTS.md` 한 줄) 또는 `AGENTS.md`(CLAUDE.md 복사본)를 만든다. 작업 폴더 아래 2단계까지의 하위 폴더(예: 하위 저장소 `app-agent\AGENTS.md`)도 원본 지침 파일이 있는 곳마다 같은 규칙으로 만든다(숨김·`node_modules`·빌드 폴더는 보지 않음). 이미 있으면 건드리지 않는다.

아이콘: `gui/icons.js` 는 `npm run icons`(Phosphor Icons, MIT)로, 앱 아이콘 `src-tauri/icons/` 는 `gui/assets/icon.svg` 에서 `npm run app-icon` 으로 만든다. 글꼴은 Pretendard(OFL), 마크다운 해석은 marked(MIT, `gui/vendor/`).

## 개발용 CLI

Plan 1 코어(계정 등록/전환)는 GUI 없이 `npm run cli` 로 직접 확인할 수 있다.

```bash
npm run cli -- list                                     # 등록된 계정 목록 (스냅샷 경로 포함)
npm run cli -- current <codex|claude>                   # 현재 로그인된 계정
npm run cli -- save <codex|claude> <라벨>                # 현재 로그인을 라벨로 등록/갱신
npm run cli -- switch <codex|claude> <라벨>              # 앱 종료 → 백업 → 인증 교체 → 재실행
npm run cli -- restore <codex|claude> <backup.bin 경로>  # 백업/계정 스냅샷 파일에서 직접 복원
npm run cli -- rename <codex|claude> <라벨> <새라벨>      # 등록된 계정의 라벨만 변경
npm run cli -- delete <codex|claude> <라벨>              # 등록·저장된 스냅샷 삭제 (앱의 로그인 상태는 그대로)
npm run cli -- add <codex|claude>                       # 로그아웃 없이 새 계정 추가 준비 (저장·백업 → 로그인 정보 비움 → 앱 재실행)
npm run cli -- sessions <codex|claude> [--all]          # 세션 목록 (검증용): 키 · 제목 앞 40자 · 갱신일 · 대화 기록 유무 (--all: 보관됨·서브에이전트 포함)
npm run cli -- import <codex|claude> <키...> --to <codex|claude> [--account <라벨>] [--copy] [--copy-instructions] [--copy-folder] [--full-tool-log]   # 세션 이관
```

`switch`/`restore`/`add` 는 기본적으로 앱을 정상 종료 요청한 뒤 3초 안에 닫히지 않으면 확인 없이 강제 종료하며, 진행 단계를 `  · <단계>` 로 출력한다. 다른 계정을 추가로 등록할 때는 앱에서 직접 로그아웃하지 말고 `add` 를 쓴다 — 로그아웃은 그 계정의 토큰을 서버에서 즉시 폐기한다(관찰 기록: [Phase 0 검증 런북](docs/verification/phase0-auth.md)).

`sessions` 로 출력된 키를 `import` 에 넘긴다(한 번에 최대 200개). 예: `npm run cli -- import claude claude:code:local_<id> --to codex`. `--to claude` 는 Codex 원본이면 변환 이관, Claude 원본이면 다른 계정으로의 포크(Code 세션만)이며, `--account` 는 대상 Claude 등록 계정 라벨(생략하면 현재 로그인 계정), `--copy` 는 이미 이관한 세션도 새 복사본으로 만든다(기본은 건너뜀). `--copy-instructions` 는 지침 파일을, `--copy-folder` 는 GPT 대화 폴더를, `--full-tool-log` 는 도구 실행 기록 전부를 옮긴다(GUI 의 같은 이름 옵션). 대상 앱을 종료했다가 다시 실행하며, 항목마다 `가져옴`/`공유됨`/`건너뜀`/`실패` 를 출력한다. 실제 앱에서의 검증 결과와 수행 방법은 [Phase 0 이관 검증](docs/verification/phase0-migration.md) 참고.

`--with-app-profile` 로 저장한 계정은 `switch`/`restore` 에도 같은 옵션을 줘야 한다 — 다르면 범위(스코프) 불일치로 아무것도 쓰지 않고 취소된다. 전체 사용 순서와 알려진 제한은 [Phase 0 검증 런북](docs/verification/phase0-auth.md) 참고.

## 고지

비공식 커뮤니티 도구이며 OpenAI / Anthropic 과 무관하다. 앱 내부 파일 형식에 의존하므로 앱 업데이트 시 동작하지 않을 수 있다. **본인 소유 계정** 간 전환 용도로만 사용한다.
